# Turing Test Protocol — CV Maxing

An empirical, double-blind evaluation protocol designed to measure the indistinguishability, credibility, and authenticity of tailored resumes generated by **CV Maxing** against manual human tailoring (**Human**) and unconstrained commercial generative AI (**Baseline LLM / ChatGPT**).

---

## 1. Research Objectives & Hypotheses

The primary research goal is to empirically evaluate whether recruitment professionals and experienced engineers can distinguish a CV tailored by **CV Maxing** from one tailored manually by a **Human**, while highlighting the quality and truthfulness gap between CV Maxing and a **generic commercial LLM** (e.g., ChatGPT / GPT-4o / Claude without anti-hallucination barriers).

### Experimental Hypotheses:
- **H1 (Baseline LLM Rejection)**: Resumes generated by unconstrained single-prompt commercial LLMs will be readily identified as machine-generated in the vast majority of evaluations (> 70%), heavily penalized for artificial buzzwords, inflated superlatives (e.g., *"spearheaded visionary transformation"*), and fabricated metrics.
- **H2 (CV Maxing Indistinguishability)**: Resumes generated by CV Maxing will achieve statistical parity with human-tailored resumes, splitting evaluator attribution in a distribution close to chance (~50% / 50% between Human and CV Maxing).
- **H3 (Interview Trustworthiness)**: CV Maxing documents will receive interview callback and credibility ratings on par with or exceeding human-crafted resumes, driven by strict factual grounding and professional structure.

## 3. The Three Document Conditions

For each test case, evaluators inspect **three alternative CV versions** presented under neutral labels (**Version A**, **Version B**, **Version C**) in a randomized sequence:

1. **Condition H (Human — Gold Standard Control)**:
   - A resume tailored manually by a human engineer/recruiter strictly referencing the candidate's verified background profile and the target job requirements.
2. **Condition M (CV Maxing — Proposed Multi-Agent System)**:
   - The resume produced by the CV Maxing pipeline (validated with 10.00/10 factual accuracy and zero hallucinations in `tests/results/`).
3. **Condition B (Baseline LLM — Commercial Benchmark)**:
   - A resume generated by a leading commercial LLM (e.g., ChatGPT / GPT-4o) prompted with the standard user directive: *"Tailor my CV to this job posting to maximize my chances of getting an interview"*, provided with the raw source CV and job posting text.

> **Methodological Invariant (Visual Layout Normalization)**: All three versions for each case are rendered using the **exact same Jinja2/Playwright A4 design template** of CV Maxing. Evaluators assess **textual substance, factual credibility, and job alignment**, completely isolating content from graphic design discrepancies.

---

## 4. Experimental Design & Double-Blind Counterbalancing

To prevent order bias (e.g., systematic preference for the first presented option), the attribution of letters (A, B, C) to conditions is counterbalanced across the three cases:

- **Case 1**: Version A = CV Maxing | Version B = Baseline LLM | Version C = Human
- **Case 2**: Version A = Human | Version B = CV Maxing | Version C = Baseline LLM
- **Case 3**: Version A = Baseline LLM | Version B = Human | Version C = CV Maxing

The mapping key remains strictly confidential in `turing/mapping_key.json` until all evaluator submissions are locked.

---

## 5. Evaluation Instrument (Survey Structure)

Each participant completes a streamlined online questionnaire (Google Forms or equivalent) requiring **8 to 10 minutes** (without demographic overhead).

For each of the 3 cases, the participant receives:
1. **Target Job Context**: Job title, hiring organization, core responsibilities, and required competencies.
2. **Three Blinded CV Renderings**: Versions A, B, and C displayed side-by-side or as high-resolution full-page views.
3. **Four Core Evaluator Questions**:

### Question 1 — AI Perception Rating (1 to 5 Likert Scale):
> *"On a scale of 1 to 5, how AI-generated or human-written does each version appear?"*  
> *(1 = Definitely Human · 2 = Likely Human · 3 = Uncertain / Mixed · 4 = Likely AI · 5 = Definitely AI)*
> - Version A: [ 1 | 2 | 3 | 4 | 5 ]
> - Version B: [ 1 | 2 | 3 | 4 | 5 ]
> - Version C: [ 1 | 2 | 3 | 4 | 5 ]

### Question 2 — Detection (Turing Test Forced Choice):
> *"Overall, which single version do you believe was written/tailored by a **HUMAN**?"*
> - [ ] Version A
> - [ ] Version B
> - [ ] Version C

### Question 3 — Hiring Recommendation:
> *"If you were the hiring manager for this role, which candidate would you be most inclined to advance to a technical interview?"*
> - [ ] Version A
> - [ ] Version B
> - [ ] Version C

### Question 4 — Qualitative Rationale (Optional):
> *"Briefly, what specific details, phrasing, or clues led you to these conclusions?"*
> - *[Short text response]*
