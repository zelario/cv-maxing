# Cloud & DevOps Engineer

**Company / Location:** Aether Cloud Solutions · Lisbon / Hybrid

**Role Summary:** Automating cloud infrastructure, deploying reliable CI/CD delivery pipelines, and ensuring system observability and uptime.

## Key Responsibilities:
- Automate infrastructure provisioning using Infrastructure as Code (IaC) with Terraform on AWS.
- Build and maintain automated CI/CD deployment pipelines (GitHub Actions / GitLab CI).
- Monitor production systems (Prometheus, Grafana, CloudWatch) and triage infrastructure incidents.
- Enforce cloud security posture (IAM policies, secrets management, vulnerability scans).

## Mandatory Requirements (Must-Have):
- Demonstrated hands-on experience with core AWS services (EC2, S3, RDS, VPC).
- Practical expertise writing and managing Terraform configurations.
- Strong Linux administration and scripting skills (Bash or Python).
- Solid containerization experience with Docker.

## Preferred Qualifications (Nice-to-Have):
- Official AWS certifications (e.g., AWS Solutions Architect / SysOps Administrator).
- Experience with Kubernetes container orchestration.
