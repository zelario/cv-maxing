# Fullstack Web Developer

**Company / Location:** NovaTech Studios · Lisbon / Remote

**Role Summary:** End-to-end web application development, bridging responsive, accessible user interfaces with reliable server logic and database storage.

## Key Responsibilities:
- Build interactive, performant web interfaces with React, TypeScript, and Tailwind CSS.
- Implement modular backend endpoints in Node.js or Python.
- Integrate third-party authentication, payments, and external APIs.
- Maintain high standards of web accessibility, UX responsiveness, and Core Web Vitals.

## Mandatory Requirements (Must-Have):
- Proven hands-on experience with React and modern TypeScript.
- Backend development competence in Node.js or Python.
- Deep understanding of HTML5, modern CSS3/Tailwind, and responsive web design.
- Experience with Git workflows and consuming REST/GraphQL APIs.

## Preferred Qualifications (Nice-to-Have):
- Working experience with Next.js (SSR/SSG).
- Docker containerization and relational database querying.
- Public code portfolio or open-source contributions.
