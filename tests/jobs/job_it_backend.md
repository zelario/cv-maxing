# Backend Software Engineer / Python

**Company / Location:** CloudScale Technologies · Porto / Hybrid

**Role Summary:** Engineering and maintaining distributed backend services, designing resilient REST APIs, and managing relational databases.

## Key Responsibilities:
- Develop and maintain scalable RESTful APIs using Python (FastAPI or Django).
- Design relational database schemas, transactions, and index optimizations in PostgreSQL.
- Package and standardize application environments using Docker.
- Author comprehensive unit and integration test suites.

## Mandatory Requirements (Must-Have):
- Degree in Computer Science, Software Engineering, or equivalent practical experience.
- Proven backend engineering experience with Python (FastAPI/Django/Flask).
- In-depth proficiency with relational SQL databases (PostgreSQL).
- Practical experience working with Docker.
- Strong version control skills (Git) and microservice architecture principles.

## Preferred Qualifications (Nice-to-Have):
- Asynchronous messaging queues (RabbitMQ, Kafka, or Celery).
- Basic familiarity with cloud infrastructure (AWS or GCP).
- Automated CI/CD pipeline setup (GitHub Actions / GitLab CI).
